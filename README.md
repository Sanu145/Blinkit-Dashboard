# 🛒 Blinkit Sales Analysis Dashboard

# 1. Project Title

**Blinkit Sales Analysis Dashboard |Power BI**

An interactive Power BI dashboard designed to analyze Blinkit sales, products, outlets, customer ratings, and business performance.

# 2. Short Description / Purpose

The **Blinkit Sales Analysis Dashboard** provides an interactive overview of sales and outlet performance.It helps users analyze key business metrics such as total sales, average sales, number of items, ratings, outlet size, outlet location, item type, and fat content.

The dashboard is designed to make it easy to identify **sales trends, product performance, and outlet-level insights** through interactive visualizations and filters.

# 3. Tech Stack

The dashboard was developed using the following tools and technologies:

* 📊 **Power BI Desktop** – Dashboard creation and data visualization.
* 🔄 **Power Query** – Data cleaning, transformation, and preparation.
* 🧮 **DAX** – Creation of calculated measures and KPI calculations.
* 📈 **Power BI Visuals** – Charts, cards, tables, slicers, and interactive elements.

## 4. Key KPIs

The dashboard tracks the following key performance indicators:

* 💰 **Total Sales** – Overall sales generated.
* 📊 **Average Sales** – Average sales value.
* 📦 **Number of Items** – Total number of items.
* ⭐ **Average Rating** – Average customer/product rating.
* 🏪 **Outlet Performance** – Sales analysis by outlet type, size, and location.
* 🥫 **Item Performance** – Sales analysis by item type and fat content.
* 📅 **Sales Trends** – Sales analysis based on outlet establishment year.

## 5. Key Questions / Business Insights

The dashboard is designed to answer questions such as:

* What is the total sales generated by Blinkit outlets?
* What is the average sales value?
* Which outlet type contributes the highest sales?
* Which outlet size generates the most sales?
* Which outlet location tier contributes the most sales?
* Which item categories contribute the highest sales?
* How do sales differ between Low Fat and Regular products?
* How does sales performance change based on outlet establishment year?
* How do different outlet types compare in terms of sales, items, ratings, and visibility?
* How do the KPIs change when different filters are applied?

## 6. Dashboard Features

* 🎛️ Interactive filters for **Item Type, Outlet Type, Outlet Size, Outlet Location, and Fat Content**
* 📊 KPI cards for quick performance overview
* 📈 Sales trend analysis
* 🍩 Outlet size and fat-content analysis
* 📦 Item-type sales analysis
* 🏪 Outlet-type performance table
* 📅 Calendar/Year-based analysis
* 🔄 Reset button for clearing filters
* ℹ️ Information page explaining the dashboard
* 🧭 Interactive navigation between dashboard pages
